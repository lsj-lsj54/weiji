# 需求摘要（后端视角）

产品「微积」围绕碎片时间利用与正向积分激励。完整使用层功能见产品需求分析；本仓库只承担服务端能力。

## 后端后续要覆盖的能力

1. **任务**：模板库、大目标拆解、分类/优先级、缓冲与顺延、规则匹配（时长+场景+优先级+时段+精力状态）、离线队列同步、手动输入空闲时长。
2. **专注计时**：本地计时 + 服务端时间戳校准，结果写入时间账单与积分。
3. **积分奖励**：流水号事务入账、奖励状态机、徽章、休息日规则。
4. **知识点**：结构化记录、艾宾浩斯复习任务、按标签筛选与导出。
5. **社交**：好友双向关系、组队进度、周榜 Redis ZSet、匿名广场。

## 明确不在本仓实现的能力

桌面小组件、语音交互、系统免打扰、日历导入、定位 SDK、厂商推送通道等均为客户端或第三方 SDK 职责。服务端只预留字段与同步接口。

## 本迭代已落地

- 用户认证、偏好、大目标拆解
- 任务模板/匹配/缓冲顺延、专注计时校准、时间账单
- 积分流水、奖励状态机、徽章与道具
- 知识点 + 艾宾浩斯复习任务
- 好友、组队、广场、同桌轮询、周榜
- 日历导入仅接收客户端已解析的任务 JSON；语音/OCR/OSS 只存 URL
